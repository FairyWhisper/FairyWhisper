# FairyWhisper — Developer Profile

## About Me

I’m Amanda Cunningham, a Higher Diploma student in Science in Computing with a previous academic background in virology. I’ve always been drawn to structured problem‑solving — whether that meant analysing biological systems or now designing clean, maintainable software.

I’m particularly interested in building cross‑platform apps that support reading, learning, and creativity within families. As a parent, I’ve seen firsthand how good tools can make shared learning easier and more enjoyable, and that perspective shapes the kind of projects I want to build.
